## Handoff: M1 Foundation → M2 Map + shell

- **Decided:**
  - **Stack:** Vite 8, React 19.3, TypeScript 6.0.3 (pinned because typescript-eslint needs <6.1), Zustand 5, d3-geo, Vitest 5 with jsdom, ESLint 10. zod and tsx are dev-only. Runtime dependencies are only react, react-dom, zustand and d3-geo.
  - **Data:** curated JSON is the editable source of truth (D4). It holds 19 corrections in `curated/corrections.json` and 44 `unverified: true` flags; country flags sit on `country_intel.json` entries. `npm run format-data` keeps the one canonical layout, and `npm run check-data` validates shapes, links, unique ids and that layout.
  - **State:** `useAtlas(selector)` to read, `atlas.*` to write. Transient events go through `src/app/events.ts` (hover, flyto, highlight, toast, starttour, ready). There is no "change" event: imperative code, such as the map engine, uses `useAtlas.subscribe`.
  - **Share links and prefs:** hash tokens and the prefs key `atlas-v2-prefs` are unchanged from v2.
  - **Boot:** `Boot` owns the loader (it replaces the static first-paint copy) and provides `useDb()`. `useT()` gives `t`, `pick`, `pickKey` and `fmt.*` for the current language.
- **Rejected:**
  - zod at runtime, which would add bundle weight for data we validate in CI
  - a global "change" bus, which React selectors replace
  - `tsc -b` project references (single tsconfig, `tsc --noEmit`)
- **Risks:**
  - Today's CSS is still one `src/styles/base.css` copied from legacy. M2 adds the shell, map and dossier CSS.
  - `legacy/` must stay until the M3 parity check passes.
  - The usage cache sometimes returns `data: null` (network). Use `lastSuccessAt`.
- **Files:** `src/{config.ts,app/*,data/*,i18n/*,features/boot/Boot.tsx,App.tsx}`, `scripts/*`, `tests/*`, `.github/workflows/ci.yml`. Ledger with rulings and deferred minors: `docs/superpowers/plans/2026-10-31-m1-ledger.md`.
- **Remaining (M2):**
  - Write the M2 plan with superpowers:writing-plans.
  - Port the map engine (`legacy/js/map*.js`, `palette.js`, `ui.js` icons, `charts.js`) and the shell (`legacy/js/shell.js`, `tours.js` content later) with their CSS.
  - Replace the placeholder `Stage` in `src/App.tsx`.
