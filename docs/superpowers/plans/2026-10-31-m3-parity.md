# M3 Dossiers, Views, Timeline, Tours (parity) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the feature gap with the live v2 site, so production can switch to the React app (spec §8 M3, parity checklist §9). The work covers:
- the dossier for every record kind
- the view host and its four views: network, compare, sources and the full timeline
- the year scrubber under the map
- the tour player

**Architecture:**
- **Approach:** same as M2. Each legacy module is rewritten as React components with the same DOM ids, classes, ARIA, strings and behaviour, so `src/styles/{dossier,views}.css` apply unchanged. d3 layouts (force, scales, axes) run inside effects on refs, as legacy does on its elements.
- **Shared code:** the lead ports `legacy/js/charts.js` to React components first (Task 1), because the dossier and the views both use them.
- **Ownership:** three implementers work in parallel, each in its own folder. The lead pre-creates every entry file (stubs) and mounts them in `Layout`, so nobody edits another's files.

**Tech Stack:** as M2.

**Spec:** `docs/superpowers/specs/2026-10-31-react-open-source-design.md` (§9 parity checklist). Prior milestones: `docs/superpowers/plans/2026-10-31-m1-handoff.md`, `docs/superpowers/plans/2026-10-31-m2-map-shell.md` and their ledgers.

## Global Constraints

- Everything in the M2 Global Constraints still applies:
  - same DOM ids and classes as v2
  - Arabic RTL default and English LTR
  - dark and light themes
  - no sideways scroll at 390 px
  - text rendered as React children; `dangerouslySetInnerHTML` only for trusted icon SVG and `esc()`-built tooltip HTML
  - features talk only through `useAtlas`/`atlas`, `onStateChange` and `events.ts`
  - each feature registers its own strings, copied verbatim
  - no git writes by implementers
  - every task ends with `npx vitest run`, `npx tsc --noEmit` and `npx eslint .` all green
- **Unverified flags:** use `db.isUnverified(kind, id)` everywhere legacy used `DB.isUnverified`/`DB.unverified`. The badge text is unchanged.
- **Corrections:** come from `db.corrections` (`{id, where, what}`), listed on the Sources view as legacy listed `DB.errata`. There is no `applied` flag any more: every listed correction is applied.

## Review Focus

1. **Selecting a record on a phone while a view is open:** the view closes and the dossier sheet opens (the legacy rule in `atlas.select`). Neither may cover the other.
2. **Opening every hash token from a cold load:** each dossier kind, `#compare-USA-CHN`, `#view-network` and `#tour-energy` all render without errors.
3. **Switching language while a dossier or view is open:** it re-renders in place, keeping the tab and scroll where legacy kept them.
4. **Timeline play/pause at the year bounds and with every category filtered out:** no crash, and an empty state is shown.
5. **A record missing optional fields** (no religion data, no intel, no events): the dossier shows the legacy "no data" lines, not blank sections.
